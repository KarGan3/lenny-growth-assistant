# Sanitized agent development records

This folder contains a curated, truthful record of the coding-agent work available in this session, including unsuccessful approaches and corrections. It is not represented as a complete raw terminal/session export. API keys, environment contents, full user history, private chats and identifying billing request IDs are omitted.

Before publishing, scan the source package and this folder for secrets. If a complete original agent transcript is available from the coding tool's session export, redact it and add it here; do not manufacture missing turns.
