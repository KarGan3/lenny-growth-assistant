# Defining Activation Milestones for B2B Onboarding

## Understanding Activation Milestones

Defining the right activation milestones for your onboarding process is crucial for measuring user engagement and retention. According to Lauryn Isford, a key metric to focus on is what constitutes an "activated user" and what milestone marks their activation.

### Suggested Application

To define your own activation milestones, consider the following:

* Identify key user behaviors that indicate engagement and retention
* Establish a clear activation metric that is highly correlated with long-term retention
* Set a high bar for activation milestones to ensure substance and commitment from users

## Step 1: Establishing a Clear Activation Metric

To effectively measure user activation, it's essential to define a clear and meaningful activation metric. According to Lauryn Isford, a key aspect of this is to determine what constitutes an "activated user" and what milestone marks the transition from onboarding to long-term retention.

* For Airtable, the activation metric was determined to be when a team of people were activated on the product and using it in a way that suggested long-term retention. [1]
* For Snyk, the activation milestone was defined as when a user fixes vulnerabilities, indicating a team's habit around the usage of the product. [2]
* For Grammarly, the activation milestone was the installation and aha moment, which carried the user for a long time. [3]

## Step 2: Identifying Key User Behaviors

To define your own activation milestones, identify key user behaviors that indicate engagement and retention. Consider the following:

* Daily frequency and retention rate are crucial for products with daily frequency
* Activation milestones should be set based on the product's goals and user behaviors
* Consider the product's core value and the team's habit around its usage

## Step 3: Setting a High Bar for Activation Milestones

To ensure substance and commitment from users, set a high bar for activation milestones. Consider the following:

* Activation milestones should be set based on the product's goals and user behaviors
* A high bar ensures that users are committed to using the product for long-term retention
* Consider the product's core value and the team's habit around its usage

## Step 4: Measuring Activation Milestones

To measure activation milestones, use metrics that are highly correlated with long-term retention. Consider the following:

* Use metrics that measure user engagement and retention
* Use metrics that measure the team's habit around the usage of the product
* Use metrics that measure the product's core value and the team's commitment to its usage

## Conclusion

Defining activation milestones for B2B onboarding requires a deep understanding of the product's goals and user behaviors. By identifying key user behaviors, setting a high bar for activation milestones, and measuring activation milestones, you can effectively measure user engagement and retention.

### Practical Recommendations

* Identify key user behaviors that indicate engagement and retention
* Establish a clear activation metric that is highly correlated with long-term retention
* Set a high bar for activation milestones to ensure substance and commitment from users
* Use metrics that measure user engagement and retention
* Use metrics that measure the team's habit around the usage of the product
* Use metrics that measure the product's core value and the team's commitment to its usage
